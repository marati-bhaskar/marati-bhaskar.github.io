Projects

2025

Performance-Driven Optimization of Parallel Breadth-First Search

Designed and programmed performance optimizations for parallel BFS, including a novel non-atomic distance update strategy and a dynamic heuristic to switch between top-down and bottom-up phases based on frontier size in Hybrid BFS.

2024

Singular Value Decomposition (SVD) Using QR Decomposition for Image Compression

Developed an SVD algorithm from scratch using QR decomposition to compute eigenvalues and eigenvectors, without using built-in libraries. Integrated the algorithm into an image compression pipeline, demonstrating dimensionality reduction and reconstruction.

2024

Approximating Lake Volume Using Numerical Integration

Extracted the lake's dimensions from Google Maps, segmented the lake into regions based on depth contours and applied the trapezoidal rule within each region to compute sectional areas. Multiplied each area by its respective depth and summed the results to approximate the lake's total volume.

2024

Solving Systems of Linear Equations Using the HHL Algorithm

Implemented the Harrow-Hassidim-Lloyd (HHL) algorithm, leveraging key quantum computing techniques such as Quantum Phase Estimation (QPE), Quantum Fourier Transform (QFT), and Inverse QFT to solve linear systems exponentially faster than classical methods under certain conditions.
